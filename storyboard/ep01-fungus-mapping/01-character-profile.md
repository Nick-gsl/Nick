## 主角：MYCELIUM NETWORK（贯穿全集）

- **物种**：*Phanerochaete velutina*（绒革菌 · Boddy/Fukasawa 实验主角）
- **视觉化**：橙黄色 (`#C8D85A`) 丝状网络，多向放射，节点处有圆形发光中心
- **体型**：以"网"而非"个体"出现；铺满画面下半部或全幅
- **标志性特征**：节点处 3–5 向放射状细丝；电脉冲是细蓝白短线（`#6FE3FF`）沿丝定向流动
- **"表情"系统**（脉冲频率 = 情绪）：
  - 密集快速脉冲 = 警觉 / 兴奋 / 接收信号
  - 稀疏缓慢脉冲 = 记忆 / 沉思 / 未激活
  - 同步爆发 = 决策 / 投票
